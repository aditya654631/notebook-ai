# Adityadhar Dwivedi — Portfolio

Static, responsive portfolio built with HTML, CSS, and vanilla JavaScript. No build step or dependencies are required.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Deploy to Vercel

Import this folder/repository as a project in Vercel. The included `vercel.json` configures it as a static site.

## Personalize

- Update project descriptions and technology tags in `index.html` to match verified implementation details.
- Add the university name and graduation year when ready.
- Add your LeetCode profile URL if you want it linked publicly.
